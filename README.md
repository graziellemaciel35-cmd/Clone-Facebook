# 📘 Clone da Página do Facebook

Este projeto é uma recriação da **página inicial do Facebook**, desenvolvida com HTML e CSS puro.  
O objetivo é estudar e praticar conceitos de layout, responsividade, tipografia e organização visual, reproduzindo uma interface real e amplamente conhecida.

---

## ✨ Funcionalidades do projeto

- 🎨 Layout inspirado no Facebook original  
- 📱 Design responsivo  
- 🧩 Estrutura organizada em seções (logo, formulário, rodapé)  
- 🔤 Tipografia semelhante à plataforma real  
- 🧼 Código limpo e fácil de entender  

---

## 🛠 Tecnologias utilizadas

- **HTML5**
- **CSS3 (Flexbox, Grid, Responsividade)**
